# Kikon_Marken_Projekt
Im Projekt geht es darum eine Anwendung zu entwickeln mit der man Logos von Marken (z.B. Audi) fotografieren kann und dann ausgewertet wird welche Marke das ist. Die App soll am Handy über PowerApp laufen und der Rechner übernimmt den Server. Die Datenbank wird durch eine SharePoint Liste umgesätzt
